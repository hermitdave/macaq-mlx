OLMoE-1B-7B TPS benchmark — M3 Max (64 GB unified memory), 256 generated tokens,
natural WikiText-2 prose prompts.

Command:
  python3 benchmarks/bench_tps.py \
      --models OLMoE-1B-7B-MLX-BF16 OLMoE-1B-7B-MLX-mxfp4 OLMoE-1B-7B-MLX-MACaQ-4.25bpw \
      --contexts 1024 8192 --max-tokens 256

=== context ~1024 tokens (prompt chars 4,096) ===
model                                    prompt tok  prompt tps  gen tok   gen tps  peak GB
OLMoE-1B-7B-MLX-BF16                            931      3244.3      256     109.6    14.47
OLMoE-1B-7B-MLX-mxfp4                           931      2478.5      256     276.9     4.46
OLMoE-1B-7B-MLX-MACaQ-4.25bpw                   931      3416.3      256     272.6     4.46

=== context ~8192 tokens (prompt chars 32,768) ===
model                                    prompt tok  prompt tps  gen tok   gen tps  peak GB
OLMoE-1B-7B-MLX-BF16                           7366      3814.3      256      89.3    15.37
OLMoE-1B-7B-MLX-mxfp4                          7366      3607.3      256     153.2     5.29
OLMoE-1B-7B-MLX-MACaQ-4.25bpw                  7366      3602.0      256     152.0     5.29

Notes:
- Decode is 2.5x faster than BF16; peak memory 3.2x lower (4-bit weights).
- The refined checkpoint is within run noise of the stock mxfp4 quantization
  (272.6 vs 276.9 at ~1K, 152.0 vs 153.2 at ~8K): refinement changes only code
  values, not the format or runtime.
- Prompt throughput is bandwidth-saturated at these lengths and tracks BF16.
